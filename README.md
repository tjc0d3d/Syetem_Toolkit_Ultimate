# 🖥️ SYSTEM TOOLKIT ULTIMATE

A comprehensive, all-in-one Windows system toolkit delivered as a single **Batch file**.

## ✨ Overview

**SYSTEM TOOLKIT ULTIMATE** is a menu-driven Windows utility that gives you fast access to the built-in Windows system tools for scanning, monitoring, maintenance, and recovery — all from one place.

## 🧩 Features

### 🔍 Scans
- [1] MRT Scan (Malware Removal Tool)
- [2] Windows Defender Quick Scan
- [3] Windows Defender Full Scan
- [4] System File Checker (SFC)
- [5] DISM Health Check
- [6] Check Disk Health
- [7] Performance Monitor Report

### 🌐 Network
- Network connections, DNS cache, flush DNS, IP configuration, ping test, traceroute, WiFi passwords, ARP / routing tables, network adapters, speed tests, TCP/IP reset, pathping diagnostics.

### 💻 Hardware Serials
- Motherboard, CPU, BIOS, and system serial numbers
- Disk drive serial numbers
- Full hardware information report

### 🖥️ System
- Processes and services, system information, user accounts, startup programs, installed programs, disk space, environment variables, driver list, scheduled tasks, running services, CPU / RAM / GPU info, benchmark, Windows activation, Bluetooth devices, printer management, motherboard info, power efficiency, driver export.

### 🔒 Security
- Firewall status, open ports, security events, failed login attempts, USB device history, password policy, audit policy, local security policy, antivirus status, BitLocker status, malware quarantine, remote desktop settings, **Defender real-time protection toggle**.

### 🛠️ Maintenance
- Clear temp files, clear DNS cache, clear recycle bin, automated disk cleanup, defragment / optimize drive, Windows updates, restore points, backup scheduler, log rotation, **SSD TRIM optimization**.

### 🔋 Power
- Battery health report, power configuration, sleep settings, power plan switching.

### 🧰 Tools
- Task Manager, Event Viewer, Device Manager, Control Panel, System Properties, Network Connections, Windows Firewall, Programs and Features, Disk Management, Services, Registry Editor, Group Policy Editor, Computer Management, Resource Monitor, Performance Monitor, Hosts File Editor, Registry Backup, Full System Report, Command Prompt, **PowerShell**, **Windows Terminal**, **Check Pending Reboot**.

## ⚙️ Requirements

- **Windows 10 / 11**
- **Administrator privileges** (the script auto-elevates via UAC when needed)

## 🚀 Usage

1. Right-click `SYSTEM_20TOOLKIT_20ULTIMATE_20v14.0.bat`
2. Select **Run as administrator**
3. Use the menu to pick a section and run the desired check / action

## 📌 Notes

- **No third-party downloads required** — everything uses built-in Windows tools.
- Reports and exports are written to `%TEMP%`.
